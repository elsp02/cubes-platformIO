
; PlatformIO template configuration file for megaTinyCore on:
; https://github.com/SpenceKonde/megaTinyCore/
;
;
; environments:
; baseplate (oldVersion): Detects the brick topology, sends it to the PC and runs the predefined prototype feedback sequence (debug version with error messages via serial possible)
; uart_baseplate (current baseplate environment): baseplate firmware expanded with PC-controlled workflow and real feedback data
; cube (oldVersion): Polls child bricks, reports its subtree to its parent and applies or relays LED feedback (contains errors)
; uart_cube (current brick firmware): corrected cube firmware expanded with orientation detection compensation for child port 1 and brick type selection in environment
; uart_test: Minimal PC <-> ATtiny UART handshake test
