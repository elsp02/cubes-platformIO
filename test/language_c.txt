PORT CONFIGURATIONS
PORTA.OUTCLR = PIN1_bm;             : clear pin 1 of PortA 
PORTA.DIRSET = PIN1_bm;             : define pin1 of PortA as output
PORTA.DIRCLR = PIN1_bm;             : define pin1 of PortA as input
  -> same also possible with wire_t data type
    w -> port -> OUTCLR = w ->pin_bm 
    => w -> port -> OUTCLR == PORTA.OUTCLR
    => w ->pin_bm          == PIN1_bm

PORTA.PIN1CTRL = PORT_PULLUP_BM     : register for PA -> config pin1 of PortA so that its internal pull up resistor is enabled
  -> same also possible with wire_t data type
    w->port->PIN0CTRL = PORT_PULLUPEN_bm

also possible with VARIABLES:
#define LED_PIN PIN1_bm             : LED_PIN variable == PIN1_bm
PORTA.DIRSET = LED_PIN;

PORTB.OUTTGL = LED_PIN              : Toggle the output state of the pin defined by LED_PIN on PORTB

b>>=1 / b = b>>1;                   : shifts all bits in b one position to the right (often used when sendings bits one after another)
b&1                                 : checks the lowest bit of b
    explanation:   0b10110101
                 & 0b00000001
                   ------------
                   0b00000001
for (uint8_t i = 0; i < b; i++)     : Start with i = 0. Repeat the loop while i < 8. After each loop cycle, increase i by 1.
i++                                 : increment i 
b |= (1 << i)                       : set bit i in b to 1 
    (1 <<i) Wert 1 wird binär als 0000 0001 dargestellt. Durch den Shift-Operator << wird dieses einzelne Bit um i Stellen nach links verschoben
^=                                  : (bitwise?) xor          
==                                  : compare for equality
!=                                  : not equal
&upstream[i]                        : address of the array element upstream[i]

&: (0x03 & 0x01) != 0               : bitwise AND Operator where 0x01 acts as a bitmask to see if first bit of 0x03 is set (1)
|                                   : bitwise OR
/                                   : Division
